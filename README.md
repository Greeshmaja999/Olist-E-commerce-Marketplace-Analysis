# Olist-E-commerce-Marketplace-Analysis
E-commerce marketplace analysis using MySQL and Power BI

Project Overview

An exploratory analysis of the Olist e-commerce marketplace dataset using MySQL, with the objective of understanding customer purchasing behaviour, payments, orders and delivery performance.

Tools

MySQL: Data exploration and SQL analysis

Power BI: Dashboard development (in progress)

Dataset

The Olist Brazilian E-Commerce dataset is publicly available on Kaggle. See the original dataset source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Current Status

SQL exploratory analysis is available in this repository. Power BI dashboard development is in progress.
